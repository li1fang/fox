# Fox 0.6.2 旋转与快捷项候选

日期：2026-10-17。目标版本：0.6.2 / build 17。范围见 [旋转与快捷选择 V1](IPHONE_ROTATION_AND_QUICK_CONTROLS_V1.zh-CN.md)。只更新 iPhone；iPad 真机和 Fox Say 不变。

## 改动

- 横屏视觉页直接显示动作、追踪手臂两个分段选择；就位、计数和报告未完成时保持原锁定规则。二级设置保留相机、机位、参数和诊断。
- 横屏训练准备区可直接选择观测手臂；有本组观测证据后不可覆盖，组中不替换动作。
- 正式视觉页及训练内相机共用固定槽位布局，旋转只重新安放同一个预览；竖屏仍为相机优先，横屏仍为左控制/右全高相机，图像等比完整显示。
- 按实际方向、镜像和连接变化配置预览，不随骨架每帧重设；增加限定于方向变化的 0.25 秒过渡，遵循减少动态效果。计数器、门槛、连续性保护、档案格式不改。
- 半透明节奏方块、智能暂停/恢复、动作示范只登记 [三阶段概念](../fitness/VISUAL_GUIDANCE_CONCEPT_V0.zh-CN.md)，本版不实现。
