日期：2026-10-17。版本：0.6.1 / build 16。范围见 [iPhone 训练布局 V1](IPHONE_TRAINING_LAYOUT_V1.zh-CN.md)。只部署到既有 iPhone；iPad 真机保持用户认可的 0.6.0 / 15，Fox Say 不变。

## 页面安排

- 竖屏视觉：最小导航、次数与状态、完整等比相机画面、主要操作；其余内容进入「视觉设置与报告」。
- 横屏视觉：左栏容纳导航、次数/状态、设置与开始/暂停/核对；右栏独占完整安全高度的相机区域。不在画面上方或下方再放整行控件，不裁掉采集内容来铺满。
- 训练内相机采用同样的横屏左右分栏；普通训练则在左栏放目标/重量和操作，右栏放用时与节奏。竖屏普通训练的核心事实也必须完整出现在首屏。
- 重量、观察侧、诊断与人工回退仍可访问；暂停中的视觉组可以直接完成核对。未启动相机时显示「相机待机」，不冒充相机故障。
- 反馈、总结、档案格式、计数算法与门禁保持原边界；不引入 AI、同步、动作质量评分或新器材。
