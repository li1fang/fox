# Fox 页面意图与审查约束

日期：2026-10-17。与正式 View、Debug 场景和证据报告配套；不是每个组件的尺寸副本。

| ID | 意图与适用范围 | 来源与强度 | 观测方法 |
|---|---|---|---|
| HOME-INPUT | 首页记录卡可输入、拍照，输入变高时不要让既有卡片跨列跳动 | 用户的卡片与输入共识；项目约束 | 同宽度输入前后比较各记录的 x；旋转允许重新排列 |
| HOME-READ | 首页是纵向浏览，卡片摘要可截断，但需要可发现的详情入口 | 用户的瀑布流方向；入口形式为本轮设计选择 | 长文字、长图、多人内容密度场景截图，查看入口与 AX 标签 |
| MEDIA-PREVIEW | 摘要中的长图允许标注后截取顶部；完整照片及字节不因此改写 | 本轮设计取舍，不是用户规定必须裁切 | 对比长图预览与详情/完整查看，原字节由功能测试验证 |
| INPUT-RECOVERY | 保存/图片失败仍保留输入和重试入口；状态显示本机保存而非同步/分析 | 现有数据行为，必须保持 | 设计场景展示失败，独立功能回归验证持久化和幂等 |
| TYPE-WINDOW | 文字可换行，辅助功能大字号切回单列；不靠整体缩小文字适配 | 现有单列策略、可读性目标 | 记录实际窗口、字号与键盘条件；首轮不声明全机型覆盖 |
| TRAIN-SOURCE | 计划、进行中与已确认回顾必须可辨别，卡片打开不能改档案 | HOME-04/训练状态机约束 | 只读投影单测及文件指纹前后比对，UI 路径回归 |
| TRAIN-PRIMARY | 训练中当前动作/组次、观测和暂停优先，诊断为次要入口 | 用户少操作目标；具体分区为设计选择 | 等待/活动/暂停/休息/反馈状态的几何和截图 |
| TRAIN-JOURNEY | 普通训练无需进入实验室；计划主操作固定可达，活动训练集中于当前组，实验草稿与诊断按需展开 | 2026-10-26 完整故事选择；沿用 B，不增加每组多页向导 | 首页到计划、四组、休息、总结、回看真实交互；首次使用者仍需实际验证 |
| TRAIN-MODE | 新训练默认按明确能力预览；视觉/无视觉共用同阶段按钮与布局，区别为相机/纯色背景、透明/实心方块与来源说明；不换用旧无视觉界面 | 2026-10-27 P1 用户澄清；既有活动会话不迁移 | 手机/平板成对开关几何断言、拒绝权限暂停恢复、手工来源保持；辅助功能大字号允许次要信息滚动 |
| TRAIN-COUNT | 空白次数是未知，不是零或计划目标；支持加减及键盘，不以隐藏原输入规避测试 | 数据事实约束，必须保持 | 空白/边界/非法值单测、禁用保存、精确输入与重开；自动来源不被人工覆盖 |
| TRAIN-RECEIPT | 只有写入成功才显示本次已保存；失败留原页可重试，历史标题/日期/状态不互相挤压 | 保存语义及窄屏截图发现 | 注入写入失败，重试只建一条记录；回看和重开断言、真实截图 |
| TRAIN-CHOICE | 观察侧临时选择只属于当前一组；新组取计划，已有观测维持锁定侧 | 四组故事发现的 UI 状态生命周期缺陷 | attempt 归属单测及换动作四组闭环；不改识别/计数/阶段算法 |
| PHONE-CORE | iPhone 的动作/组次、目标次数或时长、重量、用时/节奏和主要操作必须完整出现在训练首屏；不能只验证按钮 | 0.6.0 用户反馈；手机布局 V1 约束 | 竖/横屏逐项检查窗口包含关系，编辑重量后主屏与核对页联动，另验暂停/休息 |
| CAMERA-FULL | 手机视觉先分配主画面空间；实际采集图像等比完整显示，次数/状态不盖住图像；竖屏选择和诊断进入二级，横屏可直接选择动作/手臂，保留原锁定规则 | 用户明确要求；不为铺满裁切 | 四角栅格测试图逐角像素核对、横竖屏投影单测、正式 View 截图；不代替真相机证据 |
| CAMERA-ROTATE | 手机横竖屏重新安放同一相机预览，不销毁重建或反复配置方向；切换遵循系统过渡并尊重减少动态效果 | 用户的数秒卡顿反馈；稳定身份为本轮修复选择 | 正式 View 宿主核对 UIView 身份，真实页面双向旋转/左右横屏及计数不重置，单测重复帧的方向通知去重；不以自动化往返耗时冒充真机帧延迟 |
| EVIDENCE | fixture、静态截图、功能通过、真人相机可靠性分别报告 | 既有项目证据边界 | 每份报告带来源、场景、设备、版本/源码指纹和未知项 |
| FOLD-BASIC | Duo 仍是手机身份，但展开可采用多列首页和训练左右布局；系统活动遮挡/折痕不能盖住主要操作；保持现有 iPad 分支 | 2026-10-25 M0/M1；不含悬停专用设计 | 尺寸注入、预留区域几何、相机/档案不变测试，另做 Device Hub 实际开合；不以模拟器代替真机视觉或铰链验证 |

稀疏源码注释只解释必要取舍。动态几何从运行中提取，不另维护坐标表。明确约束可阻止回归；可发现性、主次和审美由 Agent 结合截图报告，不作为不稳定的自动 CI 判分。

当前 App 仍设置全屏；窄窗口组件预览不代表已启用 iPad 分屏。设计宿主为 DEBUG + FOX_UI_TESTING 双门禁，只用临时合成资料，系统照片选择/相机在其中不执行。Preview 与自动采集复用正式 View。

iPhone 的本轮取舍见 [训练布局 V1](IPHONE_TRAINING_LAYOUT_V1.zh-CN.md)。iPad 用户已反馈整体体验良好，保留其分支；不能以手机布局检查代替平板回归，也不把手机横屏的 regular size class 当作 iPad。
