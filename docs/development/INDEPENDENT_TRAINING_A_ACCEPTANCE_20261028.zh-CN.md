## 警告与未覆盖范围

- 新旧 iPad xcresult 均含 `Publishing changes from within view updates is not allowed` 与 Info.plist 全屏/方向支持警告。没有定位或修复其根因，不宣称无运行时警告。
- 新 iPad 日志在已完成所有方法后出现 `Failure collecting diagnostics from simulator: Process exited with error 72`，原因为 `xcrun: error: unable to find utility "simctl", not a developer tool or in PATH`。旧 P1 同样出现；这是辅助诊断采集失败，不是本次 XCTest 方法失败。原日志/xcresult 可读，回执记载拥有模拟器已释放，接收时未发现活动回归或模拟器会话锁。它不授权改全局工具链或重启长回归。
- 本包新增的等待/丢失回退在手机竖屏验证；普通模式横竖屏成对几何测试是在未启动准备的 ready 状态。**不能将后者当成新增回退入口在手机横屏等待/丢失时的专项证明。** 交付前可只补这一限定的可达性检查，不需重跑所有机型或排查旧框架；当前不据假设声称存在遮挡或需要改产品。
