# LAB-1 原生采集接口

本页描述客户端接口，不是验收通过声明。顶层格式遵循[数据契约](LAB_CAPTURE_CONTRACT.zh-CN.md)，3D 行遵循[视觉模块契约](../fitness/LAB2_VISION3D.zh-CN.md)。既有 D1 非零 UI 与完整 public 欠验独立保留。

## 入口与状态

记录首页可直接进入“采集与视觉实验”，默认自由采集；该目的页不构造 TrainingStore。原训练/计划中的“视觉实验”入口保留，默认动作评测。自由采集控制器不调用训练、计数器、就位门槛或训练保存操作。

采集阶段为 idle、starting、recording、finishing、finished、failed；相机、分析、PUMP、文件完整性另外显示。开始不依赖人或关键点，前/后摄像头与分析设置独立。设置在录制及封存期间锁定。停止、后台、离开、时长/空间限制和相机连续性变化均整理已取得资料，不代表训练完成。

停止后原件位于独立 Documents 实验目录，完全不进入旧诊断 drafts 清理器。取消导出不删除；删除需明确确认。中断后未完成的视频不冒充可播放原片，未知帧数不补零。已封存包在列出播放/导出条目前，后台核对文件路径、链接、大小及 SHA；坏包保留并单独报告，不阻断其他原件。

## 2D 旁路行

`fox.lab_pose2d.v1` 使用显式 snake_case：

| 字段 | 含义 |
| --- | --- |
| capture_id、source_id、seq | 采集、相机来源、实际相机帧序号；与 camera_frames 关联 |
| pts | 原 CMTime 的 value 字符串、timescale 整数及 epoch 字符串；不先转 Double |
| host_received_ns | 相机帧交付时同进程单调纳秒字符串；不是曝光 UTC |
| width、height、orientation、source_mirrored | 源像素几何；输出已应用方向，Vision 只接 `.up`，像素不镜像 |
| request_revision、inference_ns | 实际请求版本及本次耗时；丢弃行不冒充已执行推理 |
| state、reason、people | observed、no_observation、request_failed、dropped；失败/丢弃必须说明原因 |

每个人体包含实际返回的关节，不补缺失点。关节 name 为既有 PoseJoint 的名称，例如 leftElbow；x 向右、y 向上，图像左下为原点，坐标为归一化值；confidence 是系统返回的置信度。人体左右是解剖侧，预览镜像不交换名称。空人体写 no_observation，错误写 request_failed，不生成自动次数或阶段。

2D/3D 输入同一个 sample 和原 PTS。3D context.streamID 等于 2D source_id，segmentID 等于本段 capture_id，frameIndex 等于 seq。同源同帧不证明同人。每段最多一个在途分析，没有待处理图像队列；繁忙帧明确丢弃并记录，录像不等待推理。物理镜头/连续性改变在相机队列先封口，新来源首帧不能混入旧段。

## PUMP 与时钟

只有用户扫描并选择后才连接；最多两个稳定采集别名 pump-A/pump-B，不默认为左右臂。每个别名一个原始事件文件，通过现有只读适配器订阅 FFE1。不会发送 FFE2、阻力或模式指令，也不接管已有 delegate/订阅。停止只处理本次拥有的适配器和连接。

通知包含原始字节、连接段、序号、主机接收时刻及已有保守解析。设备 tick、实际力、绳长 SI 单位未知时保持未知。订阅无数据、收到通知、解析待核对、断开与失败分别显示。手动重连建立新的连接段；失败实例不占住重试位置，迟到旧回调不能删除新实例。旧断开未完成时不接手下一轮。

视频 PTS、主机时钟、UTC 锚点和设备采样时钟互不冒充。本轮不推断 UTC 锚点，不直接将原始 PUMP 通知转成规范 resistance 流；后者仍需单位与时间映射验收。

## 恢复与验证边界

进程中断后的日志可能有半行。恢复保留全部原字节，将这类日志声明为 `fox.lab_recovered_raw.v1`、interrupted/failed；独立消费者只验证完整性并列入 unparsed，不能称为有效姿态或帧流。结束边界来自原进程已保存的时间，不用新进程 uptime 补造实际停止。损坏/缺 context 目录逐个隔离，不自动删除。

测试分为控制器状态、视频编码/时间、永久包/恢复/完整性、2D 行、PUMP 选择/生命周期、合成原生接线及手机/平板旅程；统一登记在测试目录。运行回执保存在忽略目录，失败、0 执行和被替代候选均保留。合成通过不代表真实相机/3D 性能、真实 BLE 或人体准确率；设备与人工操作仍后置。
