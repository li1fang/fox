# 工具链过渡并存：有退出条件

更新：2026-10-25。此处是开发环境计划，不是 Duo 产品适配或训练准确率验收。

## 本轮收敛执行

以下历史章节保留发生顺序；当前配置和实际完成状态以本节及绑定候选的本地回执为准。

- 用户已授权：清理可重建构建缓存，保留记录/录像/回执；新版验收通过后移除旧 Xcode 与旧运行时。随后明确同意补装必要的通用运行时。
- 已清理 7 个白名单构建目录，先备份并校验其中 Logs/TestResults；已有 1,275 个 verification 文件前后内容一致。原始数据和旧工作树不在删除范围。
- 环境修正：iOS 27.1 / 24A94425 的 `supportedDeviceTypes` 只有 Duo；因此通用 iOS 27.0 不是冗余。第一轮创建 iPad 被拒绝，保留零步骤失败回执；确认精确创建意图未产生设备、父/子已退出后释放会话，未删除用户设备。随后先用新 Xcode + 现有通用运行时验证普通手机/平板，再补装通用新版并重新验收。
- 本地配置收敛为 Xcode 27.1 / 27A9275 + 通用 iOS 27.0；Duo 的 27.1 继续作为显式独立诊断覆盖。云端现有 26.3 / 17C529 + 26.4 是明确的兼容矩阵，不代表本地仍须保留旧安装。CI 仅新增显式 profile，不改事件、runner、触发或范围。
- 先补失败测试，再修复启动前兼容性检查：所有请求机型在获取会话和创建前核对实际 runtime 支持；无永久实例但受支持可创建临时设备，错误版本/机型不回退。运行中的候选不编辑；修订在临时工作树完成，审查后冻结为新候选。
- 删除门槛尚须本轮实际验收：新环境完整 public/native、回执复核、普通手机/平板 UI 无未解释回归；磁盘峰值足够；无活动任务及实际旧版依赖；系统权限满足。新 SDK + 旧 runtime 的绿色不能代替新通用 runtime 的验收。
- 旧 Xcode 在当前 macOS 上已超出官方支持范围，不用它冒充可用回退。回退保留源码/签名交付/本地记录及原安装来源与校验信息；必要时从 Apple 官方重新获取目标工具链并重新验收。旧系统环境本身不可凭一个 App 目录恢复。
- 退出保持本地稳定入口 `/Applications/Xcode.app` 指向验收过的新工具链，不改全局 `xcode-select`。卸载 runtime 使用 `simctl runtime delete` 的精确 image ID，不递归删 MobileAssets、不清空或删除用户模拟器数据。删除旧 Xcode 如需管理员授权，由用户在系统界面处理，不能绕过。
- 全部失败、通过和取消结果保存在忽略目录 `.tmp/verification/transition-exit-20261025`。未获完整通过、需要人工权限或资源不足时保留具体停止点，不宣布退出完成；退出后也不声称 Duo 布局、真实镜头、听感或运动准确率已通过。

## 目标与边界

短期保留稳定环境，隔离验证新版 Xcode / iOS Simulator；通过后收敛到一个主环境，失败则退出实验，不无限增加工具链和启动实例。旧环境在新环境验收前不删除；不修改全局 `xcode-select`，逐次使用 `DEVELOPER_DIR`。不动真机、签名、网络、产品功能和训练记录，不改变 CI 触发方式。

影响模块是现有环境检查、模拟器生命周期、直接 UI 测试入口和说明。先用合成测试检查错误分支，再检查真实 CoreSimulator 生命周期；完整 UI 及新版编译是不同门槛。

## 当前安装阻碍

### 2026-10-25 接续核对

**当前补记：** 用户已处理协议及系统授权，`-checkFirstLaunchStatus` exit 0，iOS 27.1 SDK 与 27.1 / 24A94425 runtime 已实际可用，Duo device type 的最低 runtime 为 27.1。只安装 iOS 符合当前范围；Xcode 自带 watchOS/tvOS/visionOS SDK 列表不等于已安装这些平台的 Simulator runtime，不删除内置 SDK。

用户已取消 27.0 下载。注册 runtime、CoreSimulator image 索引和 MobileAsset 实体目录只有旧 26.3 与新 27.1；检查到的 27.0 项是约 2.1 KiB 的目录元数据，不是 8 GB 安装包。限定检查的 Xcode/用户下载缓存未见可明确归属此次取消的大文件；没有手动删除共享缓存、索引或其他资产，也不声称穷尽全部系统缓存。未来若 27.0 实际出现，优先通过 Xcode Components 管理其精确版本，不直接递归删除 MobileAssets。

本轮接入显式 profile `xcode-27.1`，精确匹配 27.1 / 27A9275，默认 runtime 27.1；仍须显式选择独立安装的 `DEVELOPER_DIR`。旧默认、旧目录和 CI 保留，缓存目录通过既有 `FOX_IOS_UI_DERIVED_DATA` 隔离。全新 runtime 的固定机型可以从已安装 device type 创建临时实例，不依赖永久模板设备。先测试拒绝错误 build/profile、模板缺失与隔离缓存，再按冻结提交运行有界新工具链验证；结果见本地诊断回执，不将它替代完整原生/UI/真机验收。

以下段落保留同日首次安装门槛的发生顺序；当前协议门槛已解除。

用户已自行更新并重启。本机现为 macOS 27.0.1，原最低 OS 阻碍已解除；Xcode 仍为 26.3 / 17C529。旧工具链能输出版本、枚举 iOS 26.3 runtime，但 Apple 对 Xcode 26.3 的官方支持范围止于 macOS 26.x，不能把旧安装仍在或版本命令成功视为受支持的完整回退。尚未在新 OS 上验证旧项目构建；不为本轮环境接续重复无关产品验收。

选定最新适用正式版 Xcode 27.1，不默认使用 27.2 RC。Apple 当前系统要求与 App Store 商品页均支持此选择，商品页明确包含 Duo 开发支持。用户完成官方登录后，已在独立用户目录完整展开 Xcode 27.1 / 27A9275，应用 `codesign --verify --deep --strict` 通过；原安装路径和全局选择未变。首次启动停在协议，未代为接受，组件、Duo 机型与 runtime 尚未验收。

内置 Data 卷初查约 21 GiB 可用，独立展开后约 15 GiB，均为动态值。App Store 显示安装体积约 10.25 GB，Apple 查询 API 的包大小约 3.08 GB，实际独立 XIP 为 2,027,369,056 bytes；口径不同，不互相替代。新 runtime 与缓存峰值仍待核对，不能承诺现有内置空间足够完成全部验证。

用户允许使用独立外置目录，但该路径出现校验异常：复制即时核对一致，稍后重读的 SHA-256 不同，文件大小/mtime 未变且未发现写入者；解包出现 damaged / cpio read error。保留失败副本和日志，停止以该路径作为工具链目标，没有扩大到用户资料迁移或整盘修复。相同官方原包在内置盘的多次摘要保持一致，且完整展开及应用签名检查通过。这支持暂时隔离外置路径，不足以断言硬件根因或其他归档已损坏。后续如再使用外置盘，需先单独解决耐久读回问题。

官方独立下载最初要求登录，未经认证的 XIP 请求 HTTP 302 到 `/unauthorized/`；用户已自行完成登录，此门槛已解除。另一条路径也已评估：已登录的 App Store 确有 27.1 更新按钮，但本轮未点击原地更新，未改全局安装设置或旧安装。当前精确门槛是用户处理《Xcode and Apple SDKs Agreement》及随后必要系统授权；`-checkFirstLaunchStatus` / `-help` 在接受前退出 69，后者明确报告未同意协议。没有自动接受协议或通过其他工具绕过，未读取或搬运浏览器凭据。

### 2026-10-24 历史前提

2026-10-24 只读核对：本机 macOS 26.5.2，Xcode 26.3 / 17C529，唯一 iOS runtime 为 26.3；可用空间约 18 GiB，安装前须重测。[Apple 系统要求](https://developer.apple.com/xcode/system-requirements/)显示目标 Xcode 27.1 要求 macOS 26.6 或更高。因此尚未下载、安装新 Xcode 或触发系统升级。

先安排用户认可的系统升级/重启窗口。空间预算按安装包 + 展开后的 Xcode + runtime + 构建缓存峰值 + 余量计算，不能把 18 GiB 当作足够，也不凭估计宣称具体缺多少。先盘点可重建缓存，再决定清理对象；原始视频、训练记录、备份不作为默认清理目标。

同时确认旧 Xcode 在升级后 macOS 上是否受支持；不兼容时修订回退策略，不能用“旧 App 还在”冒充回退可用。Duo 入口以 [Apple Xcode 27.1 公告](https://developer.apple.com/news/?id=kkphp5qo)和安装后机型清单为准。

## T0 使用与恢复

- 本地默认固定 iOS 26.3、iPhone 17 Pro、iPad Pro 11-inch M5 12GB。`FOX_SIMULATOR_RUNTIME` 显式选其他已装运行时；目标机型/版本缺失直接失败。云端完整原生层明确固定 iOS 26.4，与既有云端诊断目标一致；不改变触发方式。
- 套件通过 `FOX_TRIAL_IPAD_SIMULATOR` / `FOX_TRIAL_IPHONE_SIMULATOR` 指定已有 UDID；直接 UI 用 `FOX_IOS_SIMULATOR`，均须属于目标 runtime。已有实例不删除。直接 UI 默认自建临时 iPad，不再使用列表首台用户设备。
- 跨工作树共享 `~/.cache/fox/simulator-session/owner.json`，记录 PID、工作树、工具链、时间、精确创建意图和已知 UDID。另一批次立即报告 busy，不无限排队，不自动抢锁。
- 套件关闭自己的同批其他实例后，检查是否存在外部已启动/正在启动实例；如有则停止，不替其他任务关闭。人工 Xcode 操作、旧脚本和其他系统用户不受此锁约束；这不是系统级排他能力。
- 正常成功/失败清理自己的临时实例，保留显式 UDID。套件与直接 UI 的正常 SIGINT/SIGTERM 取消都会等待子命令结束再清理；SIGKILL、掉电、清理失败或创建结果不确定时，owner 可能保留；这是待恢复，不是成功。清理进度逐设备保存，重试不再次删除已经成功删除的 ID。
- 恢复：读 owner 与 suite 回执，核对 PID、命令及测试子进程，不能仅凭父进程退出抢锁。确认结束后，只处理记录中自建 UDID；创建中断则以完整随机名称、runtime、机型交叉核对。保存恢复记录，确认无残留执行/自建实例后才释放对应 token 的会话。禁止按前缀批量删除、`shutdown all` 或批量 erase。

关闭模拟器保留数据，删除临时实例是另一件事。资源管理不等于证明历史 SpringBoard 崩溃或超时的根因。

## 退出条件

从新环境首次安装成功起，最多 7 天或两个实际开发候选周期（先到者）必须复盘，不人为制造重复验证。未达标不能无限延长并存。

**成功退出：** 完成 T3，既有手机/平板无未解释回归；回退路径已按当前 OS 支持范围核对；本地默认、文档与 CI 的显式兼容矩阵一致；没有其他项目/活动任务依赖旧工具链。随后核对精确移除清单，保留历史回执及记录，再执行移除。无 Duo 真机不阻止工具链迁移，但不代表真实设备验收完成。

**失败退出：** 新环境不兼容、空间不足或到复盘门槛仍阻塞，则维持旧环境主用，停止新版试验；记录原因后决定是否移除实验安装/下载缓存。旧版若已无法运行，必须报告环境阻塞，不能称为成功回退。

## 验收与当前停止点

先测试：安装顺序变化、错误 UDID/机型、第二进程争用、外部启动实例、部分创建失败、失败保留所有权、正常释放、子进程继承。测试放在既有 `tests/scripts/verification.test.mjs`，继续经过清单和 fast 层，不另建验收系统。

实际结果放入忽略目录并绑定候选提交。T0 合成/生命周期证据不代替训练 UI 完整回归。2026-10-25 当前：T1/T2 的系统、独立展开、签名、协议与 iOS 27.1 runtime 门槛已核对；T3 新工具链采用有界诊断（core/存储、双 App 构建、临时 Duo 的 App-host/启动/截图及清理），以实际回执为准，不声称完整层级通过；T4/T5 未完成。新 profile 不放宽旧版本断言，也不改变 CI。保留旧安装不等同于在 macOS 27 上拥有受支持回退，须先明确可用回退环境及全部迁移条件再退出并存。安装日为 2026-10-25，最迟 2026-11-01 或两个实际开发候选周期内复盘，无自动删旧版或自动延期。
