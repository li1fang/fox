# D1：iPad 本地关键点与双动作验证

更新：2026-10-05。目标设备：iPad Pro 13-inch（M4）。本轮只实现 D1，不提前接入 D2 训练状态机。

Fox 0.3.4 的连续性策略、参数配置与数值诊断以 [可靠性设计](D1_RELIABILITY_DESIGN.zh-CN.md) 为准。下文的 v1 计数约束保留为历史语义，不再代表 v2 行为；旧报告原样保留，不补造逐帧数据。

Fox 0.3.5 的独立主体选择、宽松就位、分开的获取/下放端点与完整视频事件证据见 [v3 视频回放](D1_VIDEO_REPLAY.zh-CN.md)。它仍是候选：左臂侧平举存在未通过事件，不能宣称两个动作全面验收完成。

## 准确目标

在 Fox 原生应用的独立「视觉」页，以 iPad 摄像头为唯一输入，在本机检测人体二维关键点，叠加可见骨架。用户明确选择「哑铃弯举（侧身）」或「哑铃侧平举（正面）」及左臂/右臂，系统记录该侧完整循环和上举、顶端停留、下放阶段的观测时长。双臂同时做时也只计所选侧，不合计双臂次数。

这里的「人物识别」是检测画面中的人体，不识别姓名、身份或声纹，也不做面部身份识别。不判断负重、肌肉发力、呼吸或医学意义上的动作安全。次数是可纠正的二维观测，不等于姿势合格判断。

## 交付范围

1. 原生相机预览、前后相机选择、横竖屏与前置镜像骨架对齐。
2. 明确区分相机权限未授予、权限拒绝、相机不可用/中断、无人、多人、关键点不清晰、等待伸展和有效计数状态。
3. 相机运行时即可点击开始，不要求点击瞬间有人或手臂可见。点击后等待单人及所选臂的肩、肘、腕稳定 0.25 秒，再显示 3、2、1；连续三秒关键点有效后自动开始计数。只要求所选臂，不强制双臂同时可见。倒计时期间无人、多人、低置信度、断帧或旋转会重新等待并重做完整倒计时；可取消准备。首次准备不创建验证起始时间，准备期不累计次数或动作阶段时长。暂停后继续也走该流程；离开页面或进入后台取消准备并停止计数、丢弃未完成循环，回到前台不自动续数。正式计数恢复仍需看到伸展位置。
4. 原始自动次数与人工修正分别保留；保存前可填写人工参考次数及备注。验证报告独立保存在 iPad，并可用系统分享导出 JSON。
5. 展示实际处理频率、Vision 耗时、关键点置信度与热状态；记录低频机位标量。0.3.4 新增可关闭的所选侧关节数值诊断与参数快照，仅用户保存报告时落库，不包含完整骨架/脸部；不保存录像、照片，不上传，不依赖服务器。
6. 现有训练和历史继续可用；D1 不自动改写 `WorkoutSession`、重量、计划或实际训练次数。

## 技术路线

- AVFoundation 采集视频，Apple Vision `VNDetectHumanBodyPoseRequest` 识别二维人体关键点。采用系统内置模型，不新增模型下载、网络服务或第三方姿态模型。
- 视频目标 720p；Vision 采样上限 12 Hz，串行处理并丢弃积压帧，采集/推理不在主线程运行。
- 输出帧和预览使用一致方向。Vision 使用已旋转的帧，关键点原点为左下；叠加时转换为预览左上坐标并处理 aspect-fit 留白、前置镜像。
- 角度在图像像素比例下计算，不能直接用未经宽高修正的归一化点。
- 阈值、去抖、连续性和计数算法放在 Foundation 核心中，以合成关键点序列验证；系统 Vision 负责人体推理，不手写人体模型。

## v1 保守计数约束（历史）

- 必须只有一个检测到的人，所选臂的肩、肘、腕置信度均不低于 0.55，且点有效、肢段不退化。
- 初始伸展阈值 150°，屈曲阈值 70°；离开伸展/屈曲的阈值分别为 130°/90°，极值位置需连续保持至少 0.18 秒。它们是初始工程参数，不是人体标准动作角度。
- 先稳定看到伸展，再经历上举、屈曲和下放，重新稳定伸展后才增加一次。每个运动阶段不少于 0.20 秒，完整循环不超过 20 秒。
- 无人、多人、低置信度、目标位置突变、相邻有效帧间隔超过 0.40 秒、相机切换/旋转/后台中断，都作废当前未完成循环。不会补算丢失期间的次数。
- 阶段时长以阈值过渡定义，不宣称精确的生物力学全幅时长。低置信度不能用最后一帧持续推算。
- 左右指人体解剖侧，前置镜像只改变显示；不自动切换追踪手臂或选择画面中“最大的人”。

## 数据与失败边界

报告 schema：`fox.vision_trial.v1`。包含设备/应用/算法版本、真实相机或测试数据来源、相机方向、所选臂、原始自动次数、人工修正、可选参考次数、各次阶段时长、有效帧/中断数、处理频率、耗时分位数与热状态。Fox 0.3.2 新增可选 `captureContext`，定义见下方；旧报告缺少此字段仍可读取，不补造历史机位。

Fox 0.3.3 新报告增加 `exercise=curl|lateralRaise`，分别绑定 `curl_2d_v1` / `lateral_raise_2d_v1`。旧报告无 `exercise` 时只允许解释为原弯举算法；重新保存档案不会给旧记录补写字段。算法与动作不匹配时拒绝保存/读取。两种动作共用原有循环门控和阶段时长结构，保留 `CurlTracker` / `CurlRepetition` 的 Swift 类型名以避免无关迁移。准备或本轮记录未保存时锁定动作/所选臂/相机；切换动作重置计数和朝向人工标签，不把建议朝向伪装成实际观测。

兼容方向是新应用读取旧报告，不承诺降级读取新算法；旧版本的弯举专用校验器可能拒绝包含侧平举的档案。不可将这种拒绝当成空档案覆盖原文件。

仅用户结束并保存后持久化报告；未保存的现场验证保留在当前运行内存中。写入失败不能显示保存成功，旧文件不能被损坏读取后的空数据覆盖。现有训练文件不受影响。测试使用独立报告文件，测试数据显式标记为 fixture，不能计入真实准确率。

另有 `vision-live-status.v1.json` 诊断收据，运行中约每两秒刷新、停止时更新。仅含时间、真实相机来源、运行状态、人数、可见点数、单帧耗时、Vision revision，以及可用的机位倾角和画面尺度；不含图像、音频或人体坐标。不将它解释为用户已保存的报告或准确率验收。

## 机位记录（Fox 0.3.2）

0.3.2 只补充观测条件，没有改变弯举计数算法或实现侧平举计数。0.3.3 在这些记录上增加独立侧平举档案；D2 仍不接入。目标是区分「侧身有效」「正面遮挡」「平板俯仰或距离变化」，避免把不同条件混成同一准确率结论。

### 屏幕倾角与镜头俯仰

使用 Core Motion 的重力向量，采集频率 10 Hz；仅在视觉相机页面活动时运行，后台或离开页面停止。选择人体朝向、进入结果核对时暂停相机和传感器，关闭选择/核对后仅在视觉页仍可见且应用处于前台时恢复预览，不自动恢复计数。选择相对参考系，不请求绝对航向、不使用磁罗盘、GPS、深度或网络。

| 字段 | 定义 |
| --- | --- |
| `gravityX/Y/Z` | 设备坐标系中的重力向量，保留以便重算；设备 +Z 指向屏幕外侧 |
| `screenInclinationDegrees` | 屏幕朝上平放为 0°，垂直为 90°，屏幕朝下平放为 180°；不能单凭该数判断所用镜头是俯拍还是仰拍 |
| `cameraElevationDegrees` | 实际所选镜头相对水平的仰角；正数朝上看、负数朝下看，水平为 0°；前后镜头符号相反 |
| `screenOrientation` | 实际界面方向：横屏左/右、竖屏/倒置或未知；不是罗盘朝向 |
| `motionStatus` | 可用、不可用、失败或 fixture；没有新鲜传感器读数时倾角缺失，而不是 0° |

计算以重力 Z 分量除以模长，夹在 [-1, 1]；屏幕倾角为 `acos(-gz)`，前置镜头仰角为 `-asin(gz)`，后置相反。零重力、非有限值或异常模长不可用；超过一秒的旧读数不可沿用。传感器失效不阻止人体识别、计数和报告保存。

### 人体朝向

`declaredBodyView` 为未标注 / 正面 / 侧面 / 背面 / 混合机位。开始前可以选择，准备或计数中锁定；结束核对时仍可改正。已标注时 `bodyViewSource=user`，未标注时为 `unlabeled`。这是整份报告的人工标签，不是自动识别，更不代表每一秒都朝向一致。

同一次报告里转过身应选「混合机位」，备注说明哪个方向成功或失败。下一轮正式对比应分开保存侧身弯举与正面侧平举的报告；单轮再转身就另存报告。不以肩宽缩小自动判定侧身，因为遮挡、旋转和不完整关键点都可能造成同样现象。

### 距离：只记录画面尺度

二维关节点只能显示投影大小，单靠大小不能可靠得到米制距离。本轮不提供 `distanceMeters`、面部尺寸、厘米标定或“你离 iPad X 米”。

`framing` 使用置信度不低于 0.55 的身体关键点，不使用脸部点。仅单人且至少四个有效身体点时生成：

- `visibleBodyPoints`：实际可用身体点数量。
- `observedWidthFraction` / `observedHeightFraction`：可见身体点的包围范围占图像宽/高的比例，不是完整人体真实外框。
- `torsoHeightFraction`：颈部与躯干根点的纵向跨度占画面高度；缺点就留空。
- `shoulderWidthFraction`：双肩横向跨度占画面宽度；缺点就留空。
- `nearImageEdge`：可见点进入画面边缘 3% 范围，提醒比较时可能有裁切。

记录图像尺寸、所选镜头、摄像头类型、变焦倍数及格式报告视场角。格式视场角不是裁切后的有效视场角，不用它宣称距离已校准。只有同一姿态、同一机位、相同变焦和方向下，尺度变化才可作为远近变化线索；侧身、弯腰、抬臂、遮挡和镜头切换都影响大小。

### 采样与兼容

`captureContext.schema=fox.vision_capture_context.v1`。正式计数期间约每秒保存一条样本，包括经过时间、界面方向、传感器状态、倾角、人数、追踪质量、累计自动次数/中断以及画面尺度。准备、暂停和核对期间不采样；继续后的经过时间保留暂停间隔。无人或多人仍记录状态，但尺度为空，不能沿用上一人的大小。

机位概况最多保留 1800 条，超出的有效采样机会累计在 `droppedSamples`；该概况不含逐帧坐标，不在后台持续采集。0.3.4 的独立 `counterDiagnostics` 可以保存有界的所选侧关节数值，详情见可靠性设计。样本在内存累积，只有用户保存报告才入库；实时诊断收据是另一份低频标量记录。新版本兼容读取原有 v1 报告；未测试降级应用能否保留新增字段。

## 首次真人测试复盘与下一轮

2026-10-05 用户确认首次报告的自动 11 次与实际一致，成功次数全部来自侧身；正面尝试完全未计数，且两种朝向混在同一份报告中。原报告 ID 为 `479C94EB-E744-4845-845B-95ADBB9331BE`，Fox 0.3.1，自动/确认均为 11，人工修正 0；当时没有朝向标签或独立人工参考次数。上述朝向结论来自用户补充，不能补写成当时传感器测量。

这只支持「一次侧身弯举案例可用」，不支持正面弯举或普遍动作准确率通过。下一轮按两个动作机位档案推进：侧身哑铃弯举先回归，再适配正面侧平举。每份记录只采用一种动作/机位，填写人工参考次数，并保留失败和遮挡，不只保存成功案例。通用二维速度计数、自动侧身判断、3D 假人和 A 姿势启动均后置。

## 双动作档案（Fox 0.3.3）

| 档案 | 测量与机位 | 初始计数门槛 |
| --- | --- | --- |
| `curl` | 所选肩–肘–腕的肘角；侧身，所选臂靠近镜头 | 原 150° / 70° 极值与 130° / 90° 滞回，完全保留 |
| `lateralRaise` | 所选肩→肘与肩→同侧髋的夹角；正面 | 放低 ≤20°，离开放低 >35°，顶端 ≥75°，开始回落 <60° |

侧平举必须只有一人，所选侧肩、肘、腕、髋均可信（≥0.55），上臂/前臂/躯干段不退化。角度以像素宽高修正，不以图像竖直方向代替躯干。髋点被遮挡或出画时明确提示，准备不通过，已开始时作废半次循环。极值稳定 0.18 秒、上举/下放至少 0.20 秒、总循环最多 20 秒；遮挡、多人、断帧、暂停和旋转继续使用原中断规则。开始仍为点击后入镜、稳定关键点、3/2/1，再等待手臂低位，而不是一看到手臂在顶端就计数。

上述角度是待真机调整的工程门槛，不是训练要求。不要为了使计数通过而强行增大动作幅度。系统不自动确认侧身/正面，不区分所有投影相近的前举、斜举或跨身运动，不确认双臂同步、站姿稳定或动作合格；不是通用速度计数器。未适配动作继续人工记录。

### 本轮真人对照顺序

1. 先侧身弯举：所选臂朝向镜头，保存一份独立报告，人工标注「侧面」和实际参考次数；确认原路径仍可用。
2. 再正面侧平举：肩、手臂、髋入镜，另存一份，标注「正面」和参考次数。先追踪同一侧便于比较；另一侧另存，不在一份报告里切换。
3. 每个档案另记录静止与一次遮挡恢复，检查没有额外次数或补算。角度/远近/朝向改变时另存报告；失败案例也保存，可用备注说明。
4. 比较自动/参考差值、有效帧、中断、阶段时长、机位样本与处理性能，不能只凭「骨架很准」判定计数通过。

软件回归与模拟器的合成循环测试可自动完成；真人次数、真实视角与投影误差必须由实际动作对照确认。本轮安装不会自动生成真实报告或给历史 11 次填入虚构朝向/参考值。

## 验收与测试

### 自动化门槛

- 角度宽高修正、前置镜像与 aspect-fit 投影正确。
- 稳定人体 + 完整循环只计一次；静止、阈值抖动、半程、过快跳变不计完整次数。
- 无人、多人、遮挡、低置信度、断帧、换目标和暂停不会继续计数；恢复需重新伸展。
- 左右臂隔离，人工修正不修改原始观测，报告保存/重载及写入失败可测试。
- 模拟器覆盖视觉入口、计数/修正/报告、权限拒绝、无人/多人状态，并回归 D0 训练流程。合成数据不作为真实 Vision 准确率证据。
- 构建、安装并启动目标 M4 iPad；相机权限由用户在系统提示中授予，不绕过。

### 真实家庭环境门槛（待实测）

1. 横屏、竖屏各确认一次骨架与人对齐；前置镜像不交换人体左右臂标签。
2. 单人、光线充足、所选肩肘腕完整入镜，做三次独立的 10 次慢速弯举验证，至少覆盖左右臂；每次自动次数与人工参考相差不超过 1 次。
3. 静止 20 秒无新增完整次数；中途遮挡 1 秒、第二人入镜和进入后台均不得继续新增次数。
4. 连续运行 3 分钟观察热状态、实际处理频率及推理耗时。初始目标：处理频率不低于 8 Hz，推理 P95 不超过 250 ms；达不到则记录并降低采样/分辨率，不虚报实时性能。
5. 保存导出后仍保留原始自动次数；无网络时能使用相机、检测与保存。机位可先以侧前方观察所选臂，避免手臂指向镜头造成二维投影退化。
