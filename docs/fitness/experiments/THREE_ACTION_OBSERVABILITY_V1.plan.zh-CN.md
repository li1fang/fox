# 三动作端侧可观察性实验 V1

日期：2026-10-23。执行顺序：高位下拉、卷腹、卧推探索。仅评测，不适配新动作、不改既有计数/离心算法、不改 UI 或训练记录。原片位于私有语料目录，后期机械打点不是同步真值。

## 先测试后执行

1. 在现有批回放增加显式 `mode: observations`，仅允许 video/cache 且 cases 为空；旧 controller 默认行为不变。结果注明控制器未运行、零计数用例和观测帧数；不能把 0 个用例显示成动作 0 次。
2. 自动测试：观测模式不能接受计数用例/诊断输入/未知模式；空或非单调缓存仍失败；取消/后台不成功；原输入和业务存储不变；旧动作回归继续通过。
3. iPad 对完整原片用相同 Vision revision 1、10 Hz、最大边 1280 提取全候选关节。逐文件摘要校验取回。确认设备/版本/输入、推理确实执行和覆盖片尾；失败不得用 Mac 推理冒充。
4. 分析脚本先用合成数据测试：无人体、单主体、多主体、缺点片段、置信阈值、时间间隙、低置信点不得生成角度、声音候选去重、错误来源/时间标签拒绝。缺点不插值，不用声音补齐姿态。

## 预先约定的观测与标签

- 保留完整时间线，人工根据视频确定训练区间、准备/退出负例；后期点击先检出候选，再检查附近画面。峰标签注明区间和不确定性，不自动将每声当一次完整动作。
- 原始可见性与主体关联分别报告。单候选不能保证就是目标；对多候选/疑似跳变人工叠图核查，不用“每帧最多关节”假装连续跟踪。
- 关节阈值主报告 0.3，另给 0.1/0.5 敏感性。报告覆盖率、连续缺点最长时长及 >0.3s、>1s 的缺点区间。阈值是本实验观测门槛，不是标准动作门槛。
- 下拉/卧推分别检查左右肩-肘-腕及双臂组合；卷腹检查两侧肩-髋-膝与颈/髋参考。角度按图像宽高换算，避免横屏归一坐标失真。
- 检查关节不合理跳跃、左右身份疑似交换和低置信区间。自动指标只能提示人工复查，不将坐标符号变化直接判为换人/换臂。
- 每个打点附近输出关节覆盖、角度/相对运动时间序列、图像叠加；核对高/低端点、相邻周期是否连续。不以总数吻合作结论，不计算动作质量总分。
- 单个视角开发片可支持“值得有限适配”的判断，不能证明真实训练泛化。若动作可见但检测失败，明确区分模型观测、主体规则和动作契约问题。

## 停点

完成三份端侧观测和可追溯分析后讨论：先进入有限适配、需要限定机位，或暂缓。默认保持 M3 下拉、M4 卷腹；卧推为独立候选。只有明确缺口才请求补录，不因一个指标不好立即要求全部重录。iPad 取回后恢复正常 Fox 入口，检查既有记录不变。
