# 三动作 iPad 可观察性评测 V1：结果与适配建议

日期：2026-10-23。依据 [预先测试计划](THREE_ACTION_OBSERVABILITY_V1.plan.zh-CN.md)。本轮完成端侧观测、后期打点附近的视觉核对及关节连续性分析，**没有运行三个新动作的计数器，也没有实现其动作适配**。

结论：**高位下拉适合进入有限适配；卷腹应先验证不依赖髋点的局部周期信号；卧推当前头端视角暂不进入正式计数。** 这不是判断 RGB 总体能或不能解决健身，也不是独立泛化验收。

## 2. 观察指标的含义

主表采用关节 confidence >= 0.3，另报告 0.1/0.5 敏感性。**覆盖率是指定区间里达到观测阈值的采样帧比例，不是准确率、动作达标率或计数成功率。** 没有逐帧手工标所有人体关节，不宣称坐标真实误差。

基线只在一帧恰有一个人体候选时取其关节；无人或多候选时弃权，不自动挑最大人体，不跨缺点插值。它是诊断基线，不是已经适配新动作的生产主体选择器。原候选全部保留，便于分别分析识别与选择问题。

| 动作及审阅训练区间 | 主要结果 | 连续性解释 |
| --- | --- | --- |
| 下拉：15.0–50.0 秒，350 帧 | 双臂肩/肘/腕同时可用 **100%**；0.5 阈值下 **96.6%** | 此区间每帧单候选；0.3 下无双臂缺点，0.5 下最长缺点约 0.2 秒；未触发大跳跃/左右交换筛查 |
| 卷腹：5.5–26.4 秒，209 帧 | 可见侧右肩 **100%**、右膝 **98.6%**；两点组合 **98.6%** | 组合最长缺点约 0.1 秒；0.5 下仍有 94.7%。这只能支持局部相对运动，不等于髋或脊柱可测 |
| 卷腹：同一区间 | 右髋及肩-髋-膝组合仅 **7.7%** | 最长连续缺点约 4.2 秒。不能因为图像看起来有完整人体，就使用髋角度驱动启动或计数 |
| 卧推：19.5–66.0 秒，465 帧 | 基线双臂组合 **64.9%**，最长缺点约 **1.1 秒** | 18 帧无人候选、55 帧多候选；还存在高置信左右标签交换，单看覆盖率会高估稳定性 |

全片结果也保留，但不把走近镜头、坐下准备和离开时的缺点混成训练阶段失败率。卧推前段约 8 秒有一次躺下/准备尝试，随后重新坐起；未将全部前段标成“应当零次”的强负例。

物理相机倾角、镜像状态及拍摄设备仍未确证；画面方向变换不等于陀螺仪测量。不要求摄像头垂直，也没有证明垂直更好。

## 3. 后期打点与动作周期

用户确认声音为看回放后补录。本轮先用 10ms RMS 包络检出候选，再观察其附近 0.5 秒间隔的图像及端点附近 0.3–0.5 秒间隔图像。窗口为助手人工审阅的粗区间，**不是逐帧真值，也不是用户对实际次数的新确认**。

| 动作 | 保留的六个打点候选时间（秒） | 额外声响处理 |
| --- | --- | --- |
| 下拉 | 18.36、23.94、29.88、35.69、41.55、47.67 | 50.79 秒弱脉冲出现在站起退出，不当成新峰 |
| 卷腹 | 7.81、10.67、15.12、19.02、22.21、26.08 | 六个候选均与抬起峰附近对应 |
| 卧推 | 22.81、30.20、39.27、47.16、55.92、63.96 | 57.77 秒弱脉冲处于放下途中，不当成新伸臂峰 |

三段各找到六处可审阅的峰附近画面；各前五处能配对到起点、峰和返回端点，最后一次都转入收尾，未标为相同形式的普通完整返回。**这不否定最后一次运动，也不自动宣称每段只有五次；“已到峰”和“返回阶段是否完成/可测”是两个事实。** 适配时应明确末次结束的记录规则，不能删除已经发生的运动，也不能凭空补全离心时长。

声音与峰区间并非精确同步，例如卷腹第二声 10.67 秒早于本次粗审的峰区间 10.8–11.8 秒。可用声音定位邻域，不应拿所有声响套一个固定延迟或把峰间距当成下放时长。音轨没有参与姿态推理或生产计数。

### 下拉：适配依据较充分

六个峰附近，左右肘角和腕相对肩的高度都呈现可区分的周期；前五个周期能对应返回。以第一周期的窗口中位数为例，左肘角约 147 -> 69 -> 151 度，右肘约 156 -> 83 -> 154 度；这是**投影角**，不是推荐动作角度。其他周期的端点并不完全相同，不宜照搬一个固定“必须完全伸直”的角度条件。

该机位基本看不到膝，鼻点也几乎不可用，但双臂信号充分。新启动合同应围绕必要上肢关节与主体连续性，不应要求全身、脸或高置信髋点。

### 卷腹：要换观测依据，不能只降门槛

髋点虽在 0.1 阈值下大部分存在，仍不能据此视作可信：例如躺下时低置信 root 曾落到躯干上方明显不合理的位置。把 confidence 一律调低可能获得“连续但错误”的信号。

本轮额外探索右肩相对右膝的图像高度：六次抬起的周期清楚，前五次能够返回，第一周期约从 -0.069 到 0.273 再回到 -0.075 个画面高度。该信号在检查髋失败后才加入，是**开发集上的后验候选**，不是预先验证成功的新算法。还需检验仅动头、抬膝、调整坐姿、机位变化时能否区分，不能据此评价脊柱卷曲、腰背稳定或动作标准性。

### 卧推：不仅是“看不见”，还有身份不稳定

六个标记附近都能人工看出伸臂峰，部分帧也有合理肘角；问题不是没有任何周期信息，而是连续性不够。

- 多候选时背景区域出现额外人体预测，不等于确认现场有第二个人。当前头端局部视角也使躯干参考不足。
- 自动筛查标出 13 条关节对交换候选、涉及 9 个时刻。本轮人工叠图复查 22.0、25.7、28.6、34.1、45.2 秒，观察到画面连续而左右臂标签颜色翻转。未宣称其余每一条都已逐帧核实。
- 为分离选择与检测，增加**后验人工限定中心区域**的诊断对照；双臂覆盖率仅从 64.9% 到 69.9%，最长缺点仍约 1 秒。固定区域没有修复标签翻转或关节缺失，不能当产品主体选择完成。
- 峰附近双臂完整覆盖约 27.3%–54.5%，恰好在需要确认端点时更不稳定。只调宽计数阈值可能掩盖错误。

## 4. 建议的下一轮边界

1. **M3 高位下拉：建议进入有限适配。** 先定背面上半身、肩肘腕的准备与保持条件；用肘角及腕相对肩的运动交叉验证周期，显式区分返回、短暂缺点、站起退出和末次已到峰但未普通返回。随后再测返回阶段的可见区间。使用现有缓存测试，不要求现在重录。
2. **M4 卷腹：条件性推进。** 不照搬肩-髋-膝角度。先针对可见侧肩/膝相对位移作限定视角实验，证明不是头动/腿动/坐起也会触发；成功后再接正式计数。当前没有相应独立负例，不能称为已经可靠。
3. **卧推：继续探索，不进入本轮正式动作适配。** 后续再决定是维护无左右语义的双臂轨迹、换更合适观察视角，还是暂不支持头端视角；本轮未做上述算法，也不引入深度/多机。

无需马上补录下拉/卷腹标准动作。进入适配后若缺负例，可在正常使用时追加短片：就位但不动、只调整身体或器械、自然短遮挡、末次结束。卧推若之后提升优先级，再讨论补侧斜视角作对照，保留当前失败样本。无需为了测试刻意疲劳或增加负重。

三份视频一旦用于实现或调参就是开发集；下一次正常训练才提供新的现场证据。视频可处理不意味着实时相机链路、性能、不同环境或新人体都已通过。
