### S2：三动作描述契约

新增 `MotionStrategy` 与三份 bundle JSON，JSON Schema 校验结构，Swift 测试验证实际准备与计次语义。参数仍只来自原 defaults；JSON 描述策略，不解释执行新规则。

| 动作 | 准备 / 计数 | 提交 / 返回观察 |
| --- | --- | --- |
| 弯举 | 所选肩肘 / 肩肘腕肘角 | 完整周期提交，保留原时长与独立返回估计 |
| 侧平举 | 所选肩肘 / 肩肘及有效躯干，腕默认可缺 | 完整周期提交，现有对侧躯干回退保留 |

代码注释说明恢复不得补造点、计数不是动作标准、观察不是肌肉真值。运行报告新增可选 `motionStrategies`，从实际执行 App 的 bundle 获取；旧报告不补写此字段。

### S3：档案和索引

新增 `vision-evidence.mjs`、`fox.vision_run.v1`：按原 job ID 保存不可变 job/status/result/settings 和 SHA-256。`vision:batch run/pull` 校验取回后自动调用归档/索引；可信失败/取消回执也可归档，退出状态仍是失败。

数据库只有 runs/cases/metrics/artifacts，位于 `.data/vision-evidence/index.sqlite`。不是用户训练数据库。重复导入不重复，同 ID 不同内容拒绝；校验失败不覆盖原档案，重建失败保留旧索引，外来数据库拒绝使用。

本机全部 **10 批**现有结果已导入：**28 个动作用例、3 个纯观测任务**。重建前后查询完全一致。无人工参考的字段保持空值，不输出准确率。旧 v1 报告缺 mode/frame count 时保留既有 controller 默认语义、不补造帧数；有专门回归测试。
