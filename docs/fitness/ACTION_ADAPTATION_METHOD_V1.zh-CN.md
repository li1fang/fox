# 动作适配与验证方法 V1

日期：2026-10-23。来源是弯举、侧平举、高位下拉有限适配及现场失败的工程实践，不是通用动作识别或医学动作质量标准。M3 软件/端侧缓存验证已完成，M4/卧推等待新正常训练录像。当前入口见 [README](README.md)。

## 1. 共用流程，不共用一套动作阈值

`输入与来源 -> 主体选择 -> 准备/倒计时 -> 动作专属几何 -> 周期计数 -> 独立节奏估计 -> 人工核对`

共用时间、主体跟踪、报告、回放和测试工具；动作的必要关节、观察机位、工作/返回方向、端点及可恢复遮挡分别定义。屏幕上的向下不是通用离心定义。计数通过不等于动作标准；节奏缺点时可以有次数但没有时长。

## 2. 每个动作的适配包

1. **使用契约**：候选机位、观察侧、器械、必要可见关节、可接受遮挡及明确不支持情形。记录实际倾角与画面尺度，不强制设备垂直，不由二维大小臆测米制距离。
2. **启动契约**：准备所需点与成功计数所需点分开。准备时允许重新入镜，计数中禁止把长失踪自动解释为同一个人回来了。
3. **周期契约**：起点、离开起点、峰端、返回、最小观察时长、半次/停留/重复帧的语义。
4. **恢复契约**：短缺点保留什么、哪些条件必须全部持续成立、长间断丢弃哪个未完成周期；不得用插值造出未观察到的峰值。
5. **节奏契约**：测量对应哪一段运动、开始估计与确认时刻分开、区间误差及不可评估原因。暂不合成动作/节奏总分。
6. **评测材料**：原视频摘要、完整画面、粗/细标签来源及不确定性、逐次事件、干扰片段、冻结配置与处理版本。
7. **退出与回退**：观察条件不满足时回退人工记录；不能要求用户扭曲训练动作来适应算法，也不能靠无限增加规则把单段素材调到总数吻合。

## 3. 三层验证必须分开

| 层 | 验证内容 | 不代表什么 |
| --- | --- | --- |
| 合成状态测试 | 端点、短缺点/混合缺点、歧义、重复时间、取消、恢复及数据保存 | 不代表真实摄像头能输出同样的点 |
| 原始全候选观测经实际控制器回放 | 主体/开始时间/逐次事件/恢复/独立离心结果，检查界面流程实际调用的控制器 | 不经过新鲜相机采集、实时帧调度或人体现场行为 |
| 新视频/正常训练 | 新机位、日常光照、疲劳、遮挡和交互负担；人工核对 | 有限成功不外推所有用户、角度、负重或背景 |

已有录像参与过调参，属于开发集。后续用户会同时补充高位下拉和卷腹；先划定开发部分与保留验证部分，条件允许再用自然训练的新片段复验，不把同一视频反复回放称为泛化提升。

逐次核对漏计、误计和完成时刻，不能用总数抵消错误。主体选择先独立检查；判断不到是谁时不把错主体的好计数算成功。峰值标签能验证事件对应，不能独自验证完整下放起止；阶段时长需要额外的起止区间标签。

## 5. 新动作进入标准

先可观察性检查，再一个动作一个动作实施：冻结观察契约和标签，先编写正/负例，再适配；自动验收旧动作不退步后，标记为有限条件下的实验动作。若必要点长期不可见或无法区分正常动作与干扰，记录失败原因并暂停，不自动跳到深度、多机或大模型。

## 6. 从 M3 得到的契约经验

弯举/侧平举按返回后完整周期提交，高位下拉按收缩峰端提交，不强行统一。峰值事实与返回观察分别保存；下拉下一峰追加前一次返回（段内索引），不回写旧事实，不把末次放松解释为离心。

注释记录不变量，三份 `motion-strategy-*.json` 记录语义并引用 defaults 数值，Swift/Schema 测试校对二者。短缺点允许保留候选，不代表时长有效。准备所需点比计数少。相机角度是条件记录，不是“必须垂直”的硬门槛。

运行档案与索引见[维护方案](VISION_STRATEGY_AND_EVIDENCE_V1.zh-CN.md)：合成、缓存回放、视频重新推理、真人训练分开；失效和取消也能查询。再跑旧素材不覆盖旧结果，不用总数吻合替代逐次核对。实时提醒、自动换臂和动作质量评分仍后置。
