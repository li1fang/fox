# Part 1 逐项验收审计

日期：2026-10-06。依据：[原始计划](REAL_EXERCISE_DAY_1_PART_1.zh-CN.md)与[执行记录](REAL_EXERCISE_DAY_1_PART_1_EXECUTION.zh-CN.md)。本表保留原范围，不以安装、回放或模拟器替代 M4 真人验收。

## 证据口径

- 核心测试证明确定性模型、计数和持久化契约；合成输入不是真人运动。
- 原生 UI 测试使用可控姿态输入，证明操作、协调层和本地档案链路，不证明相机准确率。
- Mac 视频回放证明同一开发视频的粗事件窗口，不是独立测试集或 M4 实时性能。
- 设备回执证明安装、启动和应用容器数据；真人计数、机位体验及性能需另验。
- 源码检查仅用于说明实际落点，不将未执行的分支或人工操作宣称为通过。

## 本轮续审发现与修复

`FoxRootView` 提前结束的操作此前在保存失败后仍调用停止相机，留下训练 active、相机 stopped 的不一致状态。新增 UI 测试先在这个断言失败，随后以保存成功为停止与跳转条件。测试专用的一次写入失败仅在 `FOX_UI_TESTING=1` 与 `FOX_UI_FAIL_EARLY_END_ONCE=1` 同时成立时启用，不用于真机训练。

另将后台心跳和视觉快照保存与显式操作的错误清理分开：后台成功写入不撤掉仍需用户处理的错误提示。回归测试要求提示在后台写入期间保留，关闭提示后相机与观测不丢；重试结束、确认及重启能读到原始 2 次，实际次数仍未确认。不改计数算法、参数或 Day 1 目标。

先前 build 9 的完整测试、安装回执和私人视频结果保留。补修候选 0.4.0 / build 10 的完整原生 UI 23 项通过，已重新构建、校验签名并安装启动；结果与回执已追加到执行记录，不覆盖先前证据。更新前确认无进行中训练，更新前后三个档案逐字节一致，仍无新真人测试。
