# M3 高位下拉有限适配：测试先行

日期：2026-10-23。前置证据见三动作可观察性评测 V1。本轮只做高位下拉；弯举、侧平举是冻结回归，卷腹、卧推等待后续自然训练录像。

## 使用与数据合同

- 背面上半身、固定观察臂，肩肘腕可见；不要求脸、髋、膝或设备垂直。不宣称所有倾角适用，不判断负重、肌肉发力、动作安全或双臂同步。
- 点击准备后沿用 M1 的主体选择、稳定倒计时、准备期重新获取。只需要所选肩肘可准备；计数还需要腕及明确的上方伸展起点。
- 下拉使用肘角、腕相对肩的高度共同确认起点/收缩端点，不能把普通弯举、静止停留或站起平移直接算作下拉。阈值单独配置，不改两个原动作。
- 达到稳定收缩端点即记一次，不等待返回，不把次数等同动作质量。先看到起点才允许记峰，短缺点不补造端点，长缺点保留已记次数并重新找起点。
- “最后一组无法统计离心”按每组最后一次重复理解。次数事实和返回测量独立：可见返回候选暂存，只有下一次有效峰出现后，才发布前一次返回观察。最后一次返回不纳入统计，即使随后看到放松/离开，也不补时长。
- 继续沿用追加式记录。峰值次数携带 `countingBasis=contractedEndpoint`；未观察的停留/下放时长为空。下一次峰事件可携带 `precedingReturn`，通过 repetitionIndex 明确它属于前一次，不修改已保存次数事实。没有 precedingReturn 是没有可发布测量，不是 0 秒。
- 返回阶段仅为二维可见角度反转到返回端点的持续时间，不推断生理离心。缺点/非单调等已有独立测量失败语义保留，末次一律没有自身返回测量。

## 预先测试矩阵

1. 合成：上半身可准备；重复时间拒绝；峰计次、持续峰不重复；半次/初始已收缩/仅平移/普通弯举不计；左右观察侧一致。
2. 恢复：峰前/峰后短缺点不丢已记事实；缺点不能用于端点驻留；返回缺点不伪造 measured；长缺点/中断要求重新观察起点；计数保留且不重复。
3. 返回与保存：第一峰立即保留，结束没有返回时长；两次峰发布第一次返回，末次即使普通返回也不发布自身时长；JSON 往返及训练证据验证；旧记录仍可读。
4. 实际控制器：完整 iPad 缓存走生产主体选择/3-2-1/计数/结束/保存，不跳过准备或直接注入计数器。可审阅六峰逐一对应，不以总数抵消错计；检查片头、收尾无额外次数。
5. 旧动作：现有核心、真实输入逐次回归、控制器、UI 准备测试继续通过；计数、峰/返回时间和离心观测不变。
