# 视觉训练 M1-M4：交互、端侧评测与动作扩展

日期：2026-10-23。用户授权本轮依次实施 M1、M2；通过后暂停复盘。M3、M4 等复盘及用户补充高位下拉、卷腹录像后再推进，不提前适配、不要求额外训练。

## 基线与边界

- 基线为 Fox 0.6.4/build 19，[R2 结果](LIVE_RELIABILITY_R2_EXECUTION_20261023.zh-CN.md)保留。软件回放不是新真人验收。
- M1 不改 `curl_2d_v4`、`lateral_raise_2d_v4`、计数配置、局部缺点恢复参数或离心估计器，不改历史记录及冻结策略。准备流程与运动中的主体保护分开。
- M2 复用 `FoxPoseExperimentKit`、诊断包、实际控制器回放及现有 CoreDevice 文件传递。不新建剪辑器、标注 App、云同步或常驻 iPad 服务器。
- 本轮不做自动换臂、实时质量评分/语音提示、深度、多机协作、新动作或新平台。

## 四个里程碑

| 里程碑 | 目标 | 验收与停点 |
| --- | --- | --- |
| M1 | 准备、启动和重新就位符合远离屏幕训练 | 一次准备意图在准备期间持续有效；准备时走近/走远或暂失主体后自动等待新的完整倒计时；正式计数中长失踪仍需显式重新就位。独立视觉与正式训练入口都验收，计数/离心不退步 |
| M2 | 动作适配规范与 iPad 本地回放、报告取回最小闭环 | 视频/观测输入有哈希、处理版本和时间语义；缓存回放不反复推理；新旧候选输出独立，不写正式训练。完成/失败/取消可区分，取回有完整性校验。结束后暂停复盘 |
| M3 | 首个新动作，暂定高位下拉 | 用户同时补充两动作录像后先查可观察性；先计数与恢复，再阶段测量。若素材显示卷腹更可行，可在复盘后调整顺序，不预先保证两者可用 |
| M4 | 第二个新动作，暂定卷腹 | 独立适配并回归前三动作；有限样本成功不等于通用动作质量判断。仍用单机 RGB，深度后置 |

## M1：先测试，后实施

1. 红灯：准备已绑定近处主体，随后离开超过保留窗口，再在训练位置出现。无需第二次点按钮；必须等待新 3/2/1，期间次数为零。
2. 红灯：已完成一次后长失踪，点重新就位，又因走回位置再失踪。准备不锁死；原次数/离心证据保留，半次不能跨中断续接。
3. 双动作、双侧；局部上身可见可准备，不引入全身/屏幕垂直门槛。准备就绪仍表示可以开始观察，不代表动作质量合格或必然可计数。
4. 多主体歧义不启动；恢复后完整倒计时。取消、相机中断、陈旧/重复帧不能误启动。运动中长失踪不能自动绑定路人。
5. 正式训练的准备阶段不提前计入运动时间；重新就位沿用同一组并创建观测分段，旧次数与测量保存。
6. 回归：R2 左/右真实弯举逐次事件、侧平举完整 trace、离心开发集区间及弃权、M4 缓存经实际控制器回放。历史策略依旧可精确重放。
7. UI 自动化：iPad/iPhone 现有布局内核对准备、等待、取消、重入和结束入口；保留完整相机比例，不大改布局。

## M2：有限范围

先核对现有工具，再补缺口。输入分为原视频和已保存的全候选姿态缓存，不能把缓存回放冒充重新执行 Vision。原始记录只读；候选输出包含输入摘要、配置/算法/控制流程版本、逐次事件、计数与离心字段、明确完成状态。

端侧使用显式开发任务，前台执行；中断不能出具成功报告。不需要新 App 常驻、不占用训练摄像头、不修改正式训练数据库。开发期文件取回继续用已配对设备通道，校验后接收；这不等于 CON-01 同步。

动作适配规范包含：观察机位、必要关节、起止端点、动作阶段、缺点恢复、负例、逐次标签、开发集/后续验证集边界、不可评估状态。相机俯仰是记录条件，不强制垂直。
