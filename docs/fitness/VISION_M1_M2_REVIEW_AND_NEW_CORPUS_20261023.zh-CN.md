## 2. 哪些还需要真实训练确认

后续正常训练中顺便观察即可，不为验收增加负重、训练量或刻意制造危险遮挡：

1. **准备**：点一次后走回实际位置，能否不用再伸手就进入完整 3/2/1；无需全身入镜，也不强制屏幕垂直。仍须能看到该动作必要关节。
2. **第一下与最后一下**：是否少记第一下，放下器材/调整姿势是否误增计；部分动作与完整动作分开，不以总数碰巧一致作通过标准。
3. **恢复**：自然短暂缺点后能否继续而不补算不存在的次数；长失踪后重新就位是否保留本组已有次数/测量，走回过程中是否又卡住。当前不自动换手臂。
4. **阶段测量**：自然慢放、停顿或没做完时，输出能否与录像可见的下放区间对应；缺点过多应报告不可评估，不能靠计数成功填一个时长。
5. **连续使用**：多组之后的响应、温度、相机中断、保存与核对后保留诊断录像，是否仍符合日常操作。模拟器 UI 回归不能替代这些体验。

离心字段目前是二维可见下放区间估计。已有少量开发集区间和弃权例，不是肌肉生理真值、动作标准性评分，也不是实时节奏提醒验收。计数与阶段测量要分别报告，允许计数可用而阶段时长不可评估。

## 4. 后期机械打点如何使用

用户确认：**看回放时后补打点，意图标记顶峰收缩附近**。已在清单标为 `unreviewed-post-production-peak-markers`。

- 声音用于寻找人工标签候选，不进入生产计数器，不作为动作完成的唯一真值。
- 机械声音清晰有助于找时间点，但后补的视觉判断/操作延迟可能随每次变化，不能默认整段只差一个固定偏移。
- 先在每个声音附近看视频，校对可见顶峰及完整周期；一个声音不自动等于一次完整动作。不确定时保留时间区间或未知。
- 仅顶峰标签仍有价值，足以起步核对峰事件对应关系、漏计/误计。要验证下放测量，还需在少量对应周期中补看实际下放起点和终点，不能用两个顶峰的间隔冒充下放时长。
- 不要求现在重录或补两套声音，不建设专用剪辑器/标注 App。新素材尚无人工完整次数、峰谷真值或声音对齐结果。

## 5. 三动作初步判断与下一步

以下是人工抽帧的可观察性假设，尚未运行这三段视频的 Vision，也未实现新动作：

| 动作 | 现有画面能帮助检验什么 | 主要风险与先验边界 |
| --- | --- | --- |
| 高位下拉 | 背面双臂与上半身，先检验肩/肘/腕的连续性、举高与下拉周期 | 器械/反光可能干扰；不能照搬弯举端点或要求全身。倾向保持 M3 首选，取决于实际观测 |
| 卷腹 | 侧面躯干与腿较完整，先检验身体相对运动是否可测 | 躺姿、双臂交叉、坐起准备可能干扰关节；须区分有效周期、准备和单纯头部运动，保留用户动作名称，不先给标准性结论 |
| 哑铃卧推 | 头端视角可见手臂运动，值得保留独立观察结果 | 躯干/肩参考不完整且有遮挡，不能复用站立主体门槛；可否稳定数次与能否测行程/节奏是不同问题，不预先承诺支持 |

建议下一轮先做有边界的离线可观察性评测：

1. 通过现有端侧视频提取能力保存全候选观测，分别检查主体选择、必要关节覆盖、连续缺点长度、左右身份交换；先不调次数门槛。
2. 对照后补声音核对少量峰与周期，保留准备/退出等负例，建立逐次对应，而非追求最终总数吻合。
3. 作出独立结论：适合有限适配、仅支持特定视角，或暂不可评估。再进入 M3 高位下拉，随后 M4 卷腹；卧推是范围外探索候选，不自动增加第五里程碑。
4. 新适配必须回归既有弯举、侧平举的启动、计数、恢复和离心字段。按 [动作适配规范](ACTION_ADAPTATION_METHOD_V1.zh-CN.md)记录动作/机位合同，不把“三段录像能处理”写成“三个动作已可用”。

当前批回放动作配置仍只有弯举和侧平举；视频提取能力可复用，但新动作契约/主体准备规则需要独立工作。归档清单采用 `exercise: null`、`declared_exercise` 描述新动作，避免冒充已有枚举或让旧解码器误执行旧动作算法。

本批录像一旦用于调参就是开发集，不是独立泛化测试集。现在没有重录必要；等观测数据揭示具体缺口再决定是否补视角/环境，之后用正常训练验证泛化。M1/M2 本轮停在复盘，M3/M4 的实现仍待下一轮启动。
