# 四动作入口与无视觉试练

日期：2026-10-28。用户授权设计后实施；不包含设备安装、推送或 CI 变更。

## 目标与边界

保留记录首页，以通用运动图标和文字直接选择哑铃弯举、侧平举、高位下拉、凯格尔运动；训练内也可用纵向列表选择。沿用有无视觉共用的布局、主按钮、节奏方块及系统语音输出，不新增视觉算法、ASR 或实时 AI。

凯格尔属于明确的无视觉动作：不请求相机权限、不启动相机、不产生临时录像，也不展示录像操作。方块和语音为计划节奏，不能成为实际次数或动作质量证据。试练暂设 5 个计划周期，轻收缩 3 秒、完全放松 6 秒；允许随时暂停/结束，结束后人工核对。不是个体化医疗处方，不承诺治疗效果。正常呼吸、不舒服停止；有盆底症状或不确定是否适合时先咨询专业人员。参考 [NIDDK](https://www.niddk.nih.gov/health-information/urologic-diseases/kegel-exercises) 与 [Alberta Health](https://myhealth.alberta.ca/Health/aftercareinformation/pages/conditions.aspx?hwid=stk151104&lang=en-ca)。

## 数据约束

- 新增可选的独立试练标识与单侧目标；旧 JSON 缺省保持原有双侧语义，不迁移已有会话。
- 侧平举的内部单侧观测不等于双侧均完成；新试练只核对观测侧，正式双侧计划仍逐侧确认。
- 未开始的独立试练切换必须没有已开始时长、已存组、视觉观测或重量确认；否则不替换。用户先核对保存当前训练后，才能开启下一动作。
- 换右臂创建新的单侧试练，不更改已保存的左臂事实。单侧试练允许直接结束，不强迫补练。
- 不修改计数、启动、恢复或离心测量算法；节奏新增收缩/放松标签，不把计划时长当实测离心。
- 已开始后的下一动作选择是临时意向，退出重启不保留这个选择，但必须保留当前训练。它显示在动作列表里，不能覆盖准备或丢失主体时的恢复提示。
- 导入的固定单侧计划沿用原目标侧；按时长训练不要求捏造次数。旧语音回放缺少新增字段时仍可解码，并保留原重量确认行为。

## 执行与停止条件

先跑有界失败用例，再实施，按同一源码执行宿主/核心测试和 iPhone/iPad 定向 UI；每次仅使用自有单个模拟器并释放。保留失败回执。已知动画等待只阻断受影响组，不放宽断言或恢复框架支线；空间不足、保存风险或意外源码变化先停下。

不声称模拟器证明真人识别、系统语音听感、Duo 真机或医疗效果。完成后另列通过项、阻塞项和真实体验边界。

## 实施结果

首页保留记录优先，在原训练卡内增加四个动作入口；训练标题打开纵向动作列表。未开始且没有事实的独立试练可直接切换，正式计划或已开始的训练先核对保存，再进入下一动作。保存失败保留原状态供重试。

弯举试练默认左侧，允许次级操作改为先练右侧；保存时可结束本次或保存后换另一侧，不再强迫一侧的试练补齐双侧。侧平举等动作的内部观察侧仍可在诊断区纠正，不作为显著的动作选择控件；已有正式计划的固定侧和双侧完成规则保持不变。

凯格尔使用相同主布局与按钮、纯色背景和实心方块。5 个计划周期后停止节奏与重复提示，提示用户核对；不会自动结束训练或写出实际次数。用户暂停时取消提示，结束后人工确认实际完成情况。相机权限、相机启动、临时录像和录像操作均不进入该动作流程。
