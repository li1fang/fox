## 保护边界

- 原 main、未提交源码和 15 个本地提交保留；交付分支不直接推送这 15 个未经公开审计的提交历史。
- 第一笔提交是一次如实整理的现有功能基线，不伪造过去开发的逐步提交；后续提交分开开发方式改进。
- 0.6.8/build 25 的设备及其历史证据不被新工作流覆盖。此次原生生产逻辑不改，只调整测试输入寻址/工具配置。
- 恢复点是本机副本，不声称完成异地备份。新源码、视频和业务记录仍分开存放。
- 第三方 UI 原稿的公开分发权不明确，仅保留本项目的实践分析和引用说明；私人动作标签由输入清单读取。

## 自动继续规则

每层通过后继续下一层，无需逐步用户批准。失败先保留回执、定位、修正，再新建运行；不删断言、不自动改历史答案、不把环境失败解释为算法退步。输入改变、公开权限不明、设备数据风险或需求冲突时停在具体边界。

## 审查带来的修正

独立上下文审查指出验证器也会误报成功。先加入失败反例，再修复：超时子进程退出 0、最终输入复核时取消、日志无法打开/写满、嵌套测试漏发现、Python expected failure、固定私人文件与实际消费的相邻文件错配。对应脚本测试 20 项通过；三段私人可观察性分析继续通过。第一次完整 private 运行在 UI 阶段主动取消，保留取消回执，不当作完成；最终完整结果必须与 PR 当前提交匹配。

第一轮远端 CI 揭示 Homebrew 最新版 XcodeGen 已变为 2.46，doctor 按契约拒绝。改为下载官方 2.45.3 并核对发布 SHA-256，不放宽版本检查；公开日志上传显式允许 `.tmp` 中的精确白名单文件。此类环境修复也需新提交、新回执，不复用旧提交的本地绿色。

## 完成定义

干净公开 checkout 的两条 CI 通过；private 对原动作/历史事件严格回归；新 Agent 不借聊天能找到版本、模块、测试及禁区；独立审查无未处理阻断；审计所有新提交和附件后建立 PR。已创建 PR 不等于可合并，PR 可合并不等于已合并。产品下一步仍是自然采集/试用后的复盘。
