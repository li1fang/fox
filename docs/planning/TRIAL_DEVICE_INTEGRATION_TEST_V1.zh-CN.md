# 训练候选真机视听并行验收

适用 NEXT-A5/A6。该实验检查工程并行能力，不评价新真人动作准确率或语音魅力。

2026-10-23 更新：按用户决定，本轮保持联网，不再执行断网专项。以下离线条件仅作未来实验说明，不是本轮必需操作或放行条件；分析器仍如实输出 `offlineSpeechVerified: false`。

## 先写测试

1. 指标分析器拒绝空帧、非递增时间、过少样本、缺少实际推理、异常终止、缺少启用组的真实播放回调。
2. 只有开关各三轮，且机位、帧尺寸、相机、热状态与前台状态满足对照条件，才计算可放行结果。条件不一致输出未评估，不把它算性能不退步。
3. P95 采集帧间隔的相对恶化上限 20%；实际采集丢帧率绝对增幅上限 5 个百分点。另列 Vision 处理耗时、编码丢帧、样本量和每轮结果，不能只给合并平均数。
4. 开启组实际使用生产相机、Vision 推理、无声录像、原生中文语音和 SwiftUI 叠加；关闭组只关闭引导，其余相同。测试用计划时钟驱动引导负载，不伪造真人动作记录。
5. 输出到独立验收目录；不得复用用户训练仓库或保留包目录。原始测量和录像保留以便检查实验条件。
6. 缓存回放、假音频驱动和模拟器不能满足这个门槛；真实播放回调也不能证明主观听感。

## 真机运行条件

物理 iPad 已连接并解锁，Fox 前台，不切 App。相机已授权。固定朝向和机位，在相同画面条件下交替执行关闭/开启引导，各三轮。暖机不算正式轮次。采集性能结果仅适用于该场景；若画面无人体，必须标明，不用它宣称多人或实际运动负载验收。

同时记录系统热状态、画面尺寸、设备姿态和主体覆盖；对照期间发生旋转、中断、明显机位/场景变化则不放行。不得要求用户拿重物站着等待开发测试。

离线语音另检查：需要能证明设备当时没有可用网络路径，并且本地中文声音实际启动和结束。设备网络状态不可控时保留待验证，不凭代码无网络请求就宣布离线真机通过。

先在联网状态完成候选的签名验证与正常启动，再关闭网络。开发签名的联网验证是系统前置，不是 Fox 的网络依赖；被系统拒绝启动的批次不属于语音/相机测试。断网后分别检查已运行 App 的功能与同一安装的重新打开，不能把前者冒充离线冷启动。若测试工具重新安装候选，需要重新确认验证状态，不反复在离线设备上重装。此步骤不要求卸载 App 或删除原记录。

## 证据与安装

先备份原档案和附件，再覆盖安装；保留现有 bundle ID，不卸载。每轮结果关联候选源码、版本、设备、输入配置和诊断 ID。取回后校验文件摘要；安装后比对实际业务记录与附件，而非仅比较目录数量。

设备验收结束恢复普通 Fox 入口，不留在测试页面。正常启动、签名有效期与原记录核对后，才可汇总为可试用候选。
