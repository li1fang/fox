## 范围与方法

显式盘点维护工作区和旧工作区的 vision-corpus、diagnostics、replay、evidence、observability、M2，以及现存部署/试用备份中的 FoxDiagnostics、FoxReplay、FoxTrialDeviceRuns 和 Application Support/Fox。旧工作区只读。不扫描整个个人照片库、系统目录或外盘构建缓存。Downloads 顶层未找到 MOV 或 Fox 命名资料；这不证明电脑不存在其他来源。

先核对源码格式、登记合成测试，再实施批量入口 `scripts/archive_batch.py`。按 SHA-256 去重传输；每个来源路径、资料组、原文件名和标签保留在版本化 inventory 中。相同字节不是同一训练，不依据文件名合并事件。已知诊断/corpus manifest 的大小与摘要必须相符；有问题的资料组隔离，遍历错误与未取得项显式列出。

允许修改批量工具、合成测试及登记、命令、任务契约与共享文档。输入摘要变化、输出路径碰撞、SSH 身份失败、空间不足或来源不明时停止对应导入。仅完整对象确认后发布关联清单；阶段回执失败也保留，重试使用新的回执文件。

## 工作线入口

共享连接沿用 `~/.config/fox/archive.json`。本轮完成后的私有当前目录指针为 `~/.config/fox/archive-current.json`，包含已经发布的总清单、视觉索引、iPhone 备份索引 ID；取回时用新文件名。旧清单及失败回执保留，不用旧发布结果冒充修正后的版本。

```sh
python3.12 scripts/archive.py list --tag inventory
python3.12 scripts/archive.py get <current-inventory-id> <new-local-inventory.json>
python3.12 scripts/archive_batch.py groups <local-inventory.json> --contains lat-pulldown
python3.12 scripts/archive.py get <object-id> <new-video-or-report-path>
```

目录索引保存原件 ID 与组关系，读取它不要求下载全部媒体。视觉索引区分参考片、探针、真实诊断及报告候选。iPhone 索引保留原记录 payload（含原文、时间、修订和照片信息）并关联照片对象，不做 OCR/营养/金额推断。
