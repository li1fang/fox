# P1 视觉优先统一训练

日期：2026-10-27。授权：实施 ENTRY-01；FIT-PHONE-01 的真实准备失败诊断另行排期。

## 契约

- 结果：首页记录方向保留，直接试练/继续训练可达；支持的动作默认预览；视觉开关不换布局和同阶段按钮。
- 非目标：新算法、准备门槛调整、iPhone 诊断取回、真机安装、CI/工具链改变、P2–P4、实时 AI。
- 不变量：原档案和计划不被试练覆盖；自动次数、人工确认、目标节奏分开；计数/恢复/离心核心不修改；现有活动会话不迁移其动作绑定。
- 模块：FoxNative 的入口、训练呈现、能力目录及平台协调；对应 App-host/UI 测试、现有 catalogue。
- 选择：沿用现有引导语义，视觉观察跟随/无视觉计划节奏；设置中既有选择保留。统一方块几何与外观，不新增节奏算法。
- 兼容：旧计划按精确动作 ID 在新会话副本补能力，不按名称猜测；不修改原计划/已完成记录。已有活动会话继续原绑定，不因新版打开而改写。
- 停止：记录风险、未知并发变更、工具链缺失、重复无新依据失败。已知 XCTest 动画等待只暂停受影响组，不重启采集器。

## 先测试

1. 失败回归：首页直接试练进入准备/预览而非计划编辑，不自动计时计数。
2. 宿主：能力匹配与未知/计时动作；试练不覆盖计划；已有活动会话不替换；视觉关闭保持到本次训练结束；拒绝相机不造观测。
3. 成对布局：iPhone 竖/横及 iPad 开关视觉后的按钮 ID/数量/位置、舞台和方块区域一致；相机完整比例，主要控制可达。
4. 行为：准备/暂停/恢复/完成固定主操作；相机拒绝或关闭后手工核对并保存；自动事实保留，手工值不变自动证据；旋转不重启模式。
5. 不变量：现有三动作真实控制器合成回放、阶段/返回测试、记录和存储测试，源算法无差异。私人录像未运行则明确缺测。

## 执行与验收

先单条红色 UI 测试，再实现、宿主和无键盘 UI 分组，再现有输入/保存回归。复用 runSuite、catalogue、独占模拟器租约和可追溯回执，逐台开关，仅清理本次实例。定向失败先分类，不盲跑全量。收尾 fast、独立上下文审查、冻结；完整候选受历史动画问题阻塞时保留边界，不把分组通过称作完整发布。

真机相机准确性、iPhone 未完成倒计时的原因、首次使用者可用性和听感均未由合成测试证明。本轮不更新设备。

## 实施结果

P1 代码与定向软件验证完成，尚未交付设备，也未完成首次使用者验收。

- 首页保留记录卡与近期记录；训练卡可直接试练三个已支持动作。有进行中的训练时继续原会话，原计划不被试练替换。
- 新训练按精确动作 ID 补能力。未声明次数口径的旧计划仅在新会话副本补充口径，并在开始前的计划摘要显示；显式口径冲突、未知/计时动作不强改。已有活动会话及历史记录不迁移。
- 准备、活动、暂停、休息采用同一布局；视觉开关不改变同阶段的主按钮。手机横屏相机在右，平板横屏相机在左，竖屏上下排列。旧无视觉布局已移除。
- 无视觉为纯色背景、实心方块，视觉为原比例画面、半透明方块；当前次数、目标与人工确认分开。沿用既有观测/计划节奏引导，不增加计数或离心算法。
- 预览不等于开始，不创建计数/计时事实；后台停止未启动的预览，过期回调不能重启。开始手工训练后，本组不能再改称全程视觉，下一未开始组才可开启。
- 正常字号的手机核心事实与动作按钮首屏可见；辅助功能大字号横屏优先用时/当前动作与固定主操作，其余信息可滚动。提示留在信息区，避免覆盖相机边角。
