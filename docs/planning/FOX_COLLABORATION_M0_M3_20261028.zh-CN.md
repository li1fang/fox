# Fox 协作整理 M0–M3

日期：2026-10-28。负责人：Fox｜产品与交付。目标：一个 Fox 项目、一个现有 Monorepo、三个专业工作线；用户不必自行搬运上下文。此文记录本包验收与结果，不是第二份当前状态或自动派工系统。

## 目标与不变量

- 保留原协调对话及历史，维护工作区不搬家；旧主工作区、原有改动、训练记录、录像和失败回执不动。
- 产品功能、算法、数据契约、CI、签名、真机、模拟器和构建入口均不改。只整理协作文档与应用中的项目/对话归属。
- 已安装候选、开发提交、软件验收、现场反馈分别记录；文档/组织通过不等于产品完整验收。
- 一个任务一个负责人，可跨模块闭环；四个入口不是四道审批，候选不是派工。
- 单写者覆盖代码、文档、台账、测试登记与工程生成；独立 worktree 不解除设备、模拟器和重型测试的共享限制。
